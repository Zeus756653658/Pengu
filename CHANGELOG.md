# Changelog

All notable changes to **Pengu** will be documented in this file.

## [1.1.0] - 2026-11-26
### Release Highlights
- **Stable Version 1.1.0**: Promoted **Pengu** to stable `1.1.0` (`versionCode 101000400`) with stable release channel auto-updates enabled by default.
- **Complete VidSnap UI & Media Suite**: Includes Quick Video/MP3 quality picker, Live Progress tracker, Downloads storage bar & filter tabs, Built-in "Now Playing" Video & MP3 player, In-App Browser downloader, Offline FFmpeg MP3 & Trim tools, Smart Clipboard link auto-detect, and animated startup splash.

## [1.0.0-beta.1] - 2026-11-26
### Release Highlights
- **Version 1.0.0-beta.1**: Updated versioning and build metadata cleanly as **Pengu**.
- **VidSnap-Style Modern UI**: Vibrant gradient home hub, Quick Video/MP3 quality picker sheet, Live Progress tracker (`Active`/`Completed` + speed ring), upgraded Downloads library (`All`/`Videos`/`MP3` tabs + storage bar), and Recent Downloads cards.
- **Built-in "Now Playing" Player**: In-app Video & MP3 player with animated audio waveform, speed control (`1x–2x`), seekbar, Share, Delete, and Trim/MP3 shortcut.
- **In-App Browser Downloader & Offline FFmpeg Tools**: WebView browser with automatic cookie sync + floating Download button, and offline Video-to-MP3 & Trim/Cut tools.
- **Smart Clipboard Auto-Detect & Animated Splash**: Floating one-tap banner on copied links plus smooth startup animation.
- **Auto-Update Enabled by Default**: Upgraded in-app GitHub release updater (`Zeus756653658/Pengu`) with ABI + universal APK fallback and Android 8+ install permission flow.
- **Core Engine**: Integrated with `yt-dlp`, `FFmpeg`, and `aria2c` for high-speed video/audio downloads.
- **Branding**: Package identity `com.devrayan.pengu`, unified app name `Pengu`, and custom penguin icon set.
